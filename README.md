# Shefa Venturez website

Premium static site for technology, cybersecurity and education.

## Open locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

## Placeholders to replace

- `[PHONE NUMBER]`
- `[WHATSAPP NUMBER]`
- `[EMAIL ADDRESS]`
- `[LOCATION]`
- `[SOCIAL PROFILE LINKS — add when available]`

To enable the floating WhatsApp button and header WhatsApp links, set a digits-only number on the `<html>` tag:

```html
<html lang="en" data-wa="2547XXXXXXXX">
```

The default message is:

`Hello Shefa Venturez, I would like to learn more about your services.`
