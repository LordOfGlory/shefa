How many people took the PDF

This page is not in the public menu. Only completed requests on /download/ are counted. Direct file links do not count.

1. Outlook (the live count)

Every completed request emails shefaventurez@outlook.com with the subject Shefa PDF download.

  1. Open Outlook.
  2. Search: subject:"Shefa PDF download"
  3. The number of emails is the number of downloads.
  4. Unique From addresses are unique people.

Create a rule: if subject contains “Shefa PDF download”, move to a folder named PDF downloads. The folder count is then the running total.

2. FormSubmit inbox

After you confirm the first FormSubmit email (check junk), you can also open submissions at formsubmit.co while signed in with shefaventurez@outlook.com.

3. If the count is zero

  1. Look in junk for an email from FormSubmit asking you to activate the form. Click the confirmation link once.
  2. Submit the public form yourself with a real email. You should receive “Shefa PDF download”.
  3. Do not count emails from before this form went live. Older visitors who opened the raw PDF are not in this log.
